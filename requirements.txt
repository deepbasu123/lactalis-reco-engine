# Lactalis B2B Personalized Recommendation Engine - deployer dependencies
#
#   python -m pip install -r requirements.txt
#
# Use `python -m pip`, not a bare `pip`. On Windows a bare `pip` often fails with
# "Fatal error in launcher: Unable to create process using ...python.exe..." because
# pip.exe has a stale interpreter path baked in; going through `python -m` avoids it.
#
# Optional but recommended. deploy.py needs this only for authentication; everything
# else uses the Python standard library. Without it the deployer still runs and falls
# back to prompting for a workspace URL and a personal access token.
#
# For browser sign-in you also need the Databricks CLI, which is a standalone program
# rather than a pip package (`pip install databricks-cli` gets the deprecated legacy
# one, so avoid it):
#
#   Windows : winget install Databricks.DatabricksCLI
#   macOS   : brew install databricks/tap/databricks
#   Linux   : curl -fsSL https://raw.githubusercontent.com/databricks/setup-cli/main/install.sh | sh
#
# Then:
#
#   databricks auth login --host https://your-workspace.cloud.databricks.com
#   python deploy.py
